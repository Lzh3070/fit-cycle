# 练啥 · FitCycle (极简训练循环看板)

专为健身爱好者打造的 **Rolling Split（滚动轮转分化）** 极简桌面看板应用。告别死板的“周一到周日”，做完推进下一天，临时加班顺延一天。

---

## 🌟 核心特色

1. **完全由用户自主定义（无强制默认）**：
   - 自由定义循环天数 $N$（如 3 分化、4 分化、5 分化等）；
   - 自主输入每天练什么部位（如：第 1 天背部+二头、第 2 天肩腿、第 3 天胸三头、第 4 天休息）；
   - 支持自由标记休息日、随时增删调序。
2. **滚动轮转机制（Rolling Split）**：
   - 告别固定周历：无论今天周几，做完点击「完成打卡」自动推到下一天；
   - 临时加班/疲劳：点击「顺延一天」，循环不乱套，明天继续当前训练；
   - 支持随时手动切换至指定天数。
3. **原生 Android 桌面小组件（Home Screen Widget）**：
   - **深色高质感看板**：桌面一眼看清今日训练目标、当前进度（如 `Day 1/4`）、下一轮预告与打卡状态；
   - 点击直接直达 App，极简轻便，无需在复杂菜单中寻找。
4. **轻量、零打扰、纯离线**：
   - 不设弹窗通知，零后台驻留耗电；
   - 纯本地 SharedPreferences 存储，无广告、无需注册登录。

---

## 📱 安装包下载与安装

编译好的正式版 APK 文件位于：
- `FitCycle.apk`（根目录）
- `build/app/outputs/flutter-apk/app-release.apk`

你可以直接发送到安卓手机上点击安装。

---

## 📌 如何添加桌面小组件

1. 在手机上安装并打开 **「练啥」** App；
2. 按照向导输入你的训练循环（如：天数、部位名称、休息日）并保存；
3. 回到安卓手机**桌面空白处长按**；
4. 点击底部的 **「小组件 / 微件 / Widgets」**；
5. 在列表中找到 **「练啥」** 或 **「FitCycle」**，长按拖动到桌面即可！
