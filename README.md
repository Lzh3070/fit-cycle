# 练啥 · FitCycle

专为健身训练者打造的滚动分化循环（Rolling Split）桌面看板与排期管理工具。

告别死板的自然周（周一至周日）强行捆绑。训练做完推进下一天，临时加班或疲劳顺延一天，让训练周期严格契合肌肉恢复规律。

---

## 核心设计理念

传统的周历打卡软件强行要求“周一练胸、周二练背”，一旦某天因加班、疲劳或突发事项停练，整周节奏即刻被打乱。

**FitCycle 采用滚动分化循环（Rolling Split Architecture）：**
- 循环仅由训练日与休息日的滚动队列构成，不与星期几绑定；
- 今日练完点击打卡，次日自动平滑轮转至下一计划；
- 遇到突发状况未练，点击“顺延一天”，循环绝不脱节。

---

## 主要功能特性

### 1. 自主定义分化循环
- 自由设定循环总天数（如经典 3 分化、4 分化、5 分化、PPL、推拉腿休等）；
- 自主配置每日训练重点部位（如“胸部与肱三头肌”、“背部与肱二头肌”、“腿部与核心强化”）；
- 灵活配置恢复休整日（Rest & Recovery），支持随时拖拽调序、编辑备注与增删天数。

### 2. 循环排期日历与近 7 天滚动预览 (v1.0.6)
- **月历宏观看板**：根据当前循环进度与自然日差，精准推算未来整月的训练与休息分布；
- **训练日与休息日一眼区分**：
  - 强化训练日标注翡翠绿胶囊微标签与训练项目缩写；
  - 恢复休整日标注静谧紫靛蓝色「休」字微标签，全月节奏一目了然；
- **交互式日期详情卡**：轻触月历中任意日期，即时展开该日所属循环轮次、具体训练内容与动作备注，并支持一键将当前循环对齐至该日；
- **首页近 7 天排期预览**：在看板首页集成横向滚动预览，直观展示未来一周每日是练是休。

### 3. 原生 Android 桌面小组件
- 常驻桌面，无需频繁打开应用即可掌控训练进度；
- **已练计划横线划掉（Strikethrough）**：今日打卡完成后，小组件上的训练项目（如“背和二头”）自动加上横线划掉效果并转为低饱和高级灰，右侧进度胶囊切换为实心翡翠绿高亮徽章；
- **次日零点本地自动轮转**：小组件内置本地自然日差算法，跨越午夜 0 点后由系统原生无感更新，零后台驻留保活，零额外电量消耗。

### 4. 今日打卡锁定与一键撤销
- 点击“完成今日打卡”后，主卡片与小组件牢牢保持在今日项目及“今日已练完”达成态，杜绝提前跳到次日计划造成认知混乱；
- 提供一键“撤销打卡”操作，误触打卡可瞬间恢复；
- 提供“顺延一天”操作，计划整体平移一天。

### 5. 打卡历史记录与应用内检查更新
- 本地完整归档历史打卡记录，记录每次训练的日期、分化天数与部位；
- 内置 GitHub Releases 检查更新机制，发现新版本时弹出悬浮式升级卡片，支持安全跳转外部浏览器下载。

### 6. 轻量、纯净、纯本地存储
- 零弹窗通知骚扰，零多余后台服务；
- 采用本地轻量持久化存储，无需注册登录，无任何广告，保护训练隐私。

## 页面架构概览

- **看板主页 (Dashboard)**：展示今日核心训练重点、达成状态、次日轮转预告、近 7 天排期预览条与完整循环序列轨道；
- **排期日历 (Cycle Calendar)**：提供月度宏观网格排期预览、月度训练/休息统计以及单日详细计划检视；
- **循环管理 (Cycle Editor)**：支持调整循环名称、自动/手动推进开关、增删训练日、标记休息日、调序与修改训练动作备注；
- **打卡历史 (History)**：按时间倒序展示历次打卡记录与完成部位。

## 桌面小组件添加说明

1. 在 Android 手机上安装并打开应用；
2. 按照向导完成训练循环配置（天数、部位名称、休息日）并保存；
3. 返回手机主屏幕，在桌面空白区域长按；
4. 点击弹出菜单中的 **「小组件 / 微件 / Widgets」**；
5. 在列表中找到 **「练啥 · FitCycle」**，长按小组件并拖动至桌面合适位置即可。

## 本地编译与构建

开发环境要求：
- Flutter SDK >= 3.10.9
- Android SDK (API Level 21+)
- Java 17+

构建步骤：

```bash
# 获取依赖
flutter pub get

# 静态代码检查
flutter analyze

# 编译生成 Release APK
flutter build apk --release
```

编译输出路径：`build/app/outputs/flutter-apk/app-release.apk`
